# iPhone-Dock
A minimalist wireless charging dock for iPhones, inspired by the iPhone DN40 Dock by SYJ &amp; OVERWERK. Angle and shape are changed to be more suitable as a desk clock, having a steeper angle.
Built for Hack Club Half Life.

## **Notes:**
- There are 2 versions of the 3D model, one using the Apple MagSafe charging puck, the other using the UGREEN Qi2.2 25W Magsafe Charger.
- Use the corresponding .stl file to ensure accurate fitment.
- Additional adhesive may be required to lock in the charging puck.
- As this is a 3D printed product, quality may vary depending on the printer and it's settings.

## **Assembly**##
- Insert the charging puck into the circular hole in the base.
- Attach silicone pads to base, to act as an anti-slip material.
- Stand the dock upright, and drop in the button.
